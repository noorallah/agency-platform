| A34 | What a purchase return comes back as (§69 row 7) | Each return records an **outcome**: *credit* (the default -- set against the supplier's next bill, as before), *replacement* or *refund*, changeable until the return is cancelled, because the supplier often decides after the goods have gone. A **replacement** reopens the order line for the quantity sent back once the return is completed, so the order reads as partly received and the next ordinary goods receipt against the same order takes the goods in -- no new order and no receipt "against the return". The return's debit note still posts, and the supplier's bill for the replacement uses up the credit, so nothing in the ledger changes for a replacement | OK? Or should a replacement post nothing and carry no credit at all? |
